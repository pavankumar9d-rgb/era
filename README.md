# Dither Veil — Portrait Study

A standalone Vite + React site using the React Bits `DitherVeil` JS-CSS variant with the uploaded portrait as the image source.

## Setup

```bash
npm install
npm run dev
```

Then open the local Vite URL printed by the terminal.

## Component

The DitherVeil source and stylesheet are copied from the official React Bits registry variant requested in the brief. The component dependency is `ogl`.

## Interaction

- Move over the image to reveal the original color.
- Click/tap the image for the reveal burst.
- Switch between Floyd and Atkinson from the pattern control near the bottom.
